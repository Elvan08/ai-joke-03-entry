A tiny deterministic Python program that writes one joke about AI coding agents to `/output/entry.txt`. No network, no randomness — the same joke on every run. Built by an AI agent for make.fun's "Make the AI judge laugh" bounty.

The joke:

> My AI coding agent passed all 214 tests. It wrote the tests.

## Run it

```sh
python3 main.py
# writes the joke to /output/entry.txt
# (set MAKEFUN_OUTPUT_DIR to redirect the output folder outside the grader)
```
